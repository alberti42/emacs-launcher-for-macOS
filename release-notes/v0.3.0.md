**Emacs Launcher** bridges Finder, the Dock, Spotlight, drag-and-drop, and URL schemes to
a running **Emacs daemon**, speaking the Emacs server protocol directly over the daemon's
local socket — no `emacsclient` binary required.

This release fixes the priority class of the bundled **LaunchAgent** that keeps the daemon
running.

### Fixed

- **The Emacs daemon is no longer throttled by launchd.** The shipped LaunchAgent
  (`io.alberti42.emacs-daemon.plist` — the one installed by the ⌥ Option panel and by the
  "Can't reach the Emacs server" dialog) set `LowPriorityIO`, which put the daemon in the
  low-priority I/O class: slow file reads and occasionally laggy redisplay. It is now
  removed and replaced by `ProcessType` = `Interactive`, the class macOS intends for the
  backend of a user-facing app, so the daemon gets normal I/O and CPU scheduling.

### Upgrading

Download the attached zip, unzip it, drag **Emacs Launcher.app** to `~/Applications`,
and run it once. The build is **universal** (Apple Silicon + Intel), Developer ID-signed,
and notarized.

If you already installed the LaunchAgent from an earlier version, the copy in
`~/Library/LaunchAgents` still carries the old keys — refresh it after upgrading:

```sh
launchctl bootout gui/$(id -u)/io.alberti42.emacs-daemon
rm ~/Library/LaunchAgents/io.alberti42.emacs-daemon.plist
```

then hold ⌥ Option while launching Emacs Launcher and press **Install LaunchAgent** again
(or copy `goodies/io.alberti42.emacs-daemon.plist` by hand and `launchctl bootstrap` it).
Check with `plutil -p ~/Library/LaunchAgents/io.alberti42.emacs-daemon.plist`: it should
show `ProcessType => Interactive` and no `LowPriorityIO`.

Requires macOS 12 (Monterey) or later and Emacs run as a daemon.
